# 2026-08-30

## Issue #98: captain-to-vice fallback

Implemented the approved bounded captain contingency in the canonical single-Gameweek optimiser.
The primary objective still values every ordinary XI player with unconditional expected points;
appearance probability is used only for the captain's zero-minute fallback term. A compact vice
selector and exact binary-continuous product linearisation avoid quadratic captain/vice pair
variables.

Missing captain appearance probability follows the issue literally: all-missing inputs go directly
to the existing mean-only solve, while mixed inputs first run fallback-aware and rerun mean-only if
the provisional captain lacks the probability. Results distinguish evaluated, unavailable and
explicitly disabled fallback through existing structured diagnostics. `p=1.0` remains known data,
not a missing-value fallback.

The canonical engine identity advanced to v2. An additive request flag defaults ordinary and #114
transfer-candidate evaluations to the new semantics, while the transfer optimiser's do-nothing
baseline and multi-Gameweek hold baseline explicitly retain their existing mean-only objective
basis. Their own transfer and horizon formulations were not redesigned.

Independent enumeration and synthetic counterexamples now cover exact objective equality, changed
captain choice, forced vice, near-certain appearance, mixed/all-missing inputs, negative vice value
and deterministic input ordering. The transfer and multi-Gameweek enumeration oracles explicitly
exercise their retained mean-only basis.
