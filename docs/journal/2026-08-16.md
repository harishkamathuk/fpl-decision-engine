## Journal branch policy

Issue #45 is intentionally issue-numbered because it changes `AGENTS.md`, `CONTRIBUTING.md` and
`.github/workflows/ci.yml`. Only after it is merged may standalone journal entries use
`journal/<YYYY-MM-DD>-<short-description>` without a tracking issue, and then only while their
complete pull-request diff remains under `docs/journal/`; CI enforces both conditions. Journal changes
tied to substantive work still belong on the relevant issue branch, and actionable code, architecture,
dependency, workflow or policy changes still require an issue.

The exception keeps journalling lightweight without weakening traceability for project changes.
